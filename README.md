# 📋 Project Tracker (Kanban Board)

A modern, responsive Kanban board built for tracking college, freelance, and personal workflows.

## ✨ Features
- **4-Stage Kanban Layout**: Backlog → In Progress → Review → Completed
- **HTML5 Drag & Drop**: Native re-ordering across columns (Tier 3)[cite: 2]
- **Dark Mode**: Persistent dark theme with localStorage (Tier 4)[cite: 2]
- **Dynamic Stats Summary**: Live counter for all stages (Tier 3)[cite: 2]
- **Full Card Management**: Add new projects, delete cards, and move stages (Tier 1 & 2)[cite: 2]
- **Real-Time Search**: Instant filtering by project name (Tier 2)[cite: 2]
- **Tab Synchronization**: Syncs state across browser tabs in real time (Tier 4)[cite: 2]
- **Responsive Design**: Adapts cleanly from desktop to mobile screens

## 🛠️ Tech Stack
- Semantic HTML5
- Modern CSS (Grid, Flexbox, Custom Variables, Micro-interactions)
- Vanilla JavaScript (ES6+, LocalStorage API, Drag & Drop API, Storage Event)[cite: 2, 3]
